# Getting help

- **Community:** open an issue on [GitHub](https://github.com/abahmed/kwatch/issues/new)
  or start a Discussion. Issues are public, so remove anything private first.
- **Pro:** go to [**Get help**](https://app.kwatch.dev/help). You get dedicated support:
  help with installation, and your feature requests and kwatch fixes come first.
  Pro is free during early access.

Attach a diagnostics file (below) to get to the cause faster.

## Save diagnostics to a file

Run the [installer](/kwatch-sh) and choose **Save diagnostics to file**. It
collects status, logs, events and your configuration with secrets removed, and
saves a file on your machine. Nothing is uploaded. Read the list on screen,
then attach the file when you reply to our email.

Before you ask, try [Is kwatch working?](/operations/is-kwatch-working).

## FAQ

**What does Pro support cover?**
Installing and configuring kwatch, your feature requests, and problems in
kwatch itself.
