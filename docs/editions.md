# Editions

kwatch ships in two editions from the same binary.

| | Community | Pro |
| --- | --- | --- |
| Price | Free forever | $29 per cluster per month, or $290 per year |
| Account | Not needed | Required to get a license key |
| Detection | Core pod, node and RBAC checks | All detectors |
| Root cause | Headline | Full proof and who changed what |
| Alert providers | 1 | Unlimited |
| Incident history | None | 90 days |
| HA, `/status` JSON API, flight recorder | No | Yes |

Pro comes with a 90-day free trial and no credit card. When a trial or
subscription ends, kwatch falls back to Community: detection and alerting never
stop.

See [pricing](/pricing) for the full feature table and
[License](/docs/license) for how to install a key.
