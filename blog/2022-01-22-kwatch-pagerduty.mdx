PagerDuty is a good destination when a Kubernetes failure needs an on-call
response. kwatch adds the Kubernetes context before it sends the incident: the
affected workload, likely cause, recent evidence, and what to investigate next.

<!--truncate-->

## 1. Create a PagerDuty integration

Create a service, choose an escalation policy, and add the **Events API v2**
integration. PagerDuty's [escalation policy guide](https://support.pagerduty.com/docs/escalation-policies)
and [Events API reference](https://developer.pagerduty.com/api-reference/b3A6Mjc0ODI2Nw-send-an-event-to-pager-duty)
show the current UI and integration options.

![Create a PagerDuty service](/img/blog/kwatch-pagerduty/1.png)
![Configure the service](/img/blog/kwatch-pagerduty/2.png)
![Choose an escalation policy](/img/blog/kwatch-pagerduty/3.png)
![Add the Events API v2 integration](/img/blog/kwatch-pagerduty/4.png)

Copy the service's **integration key**. It is a credential and must be stored
in a Kubernetes Secret, never as a plain value in a ConfigMap or Git repository.

## 2. Install kwatch with `kwatch.sh`

Run the supported interactive installer:

```bash
/bin/bash -c "$(curl -fsSL https://kwatch.dev/kwatch.sh)"
```

Choose **Configure notification**, select PagerDuty, and provide the
integration key. The generated configuration uses a Secret-backed file:

```yaml
alert:
  pagerduty:
    integrationKey: "${file:/config/pagerduty-integration-key}"
```

The manager installs the matching release and waits for readiness. It also
handles future configuration changes and upgrades; do not apply old release
manifests from this historical article.

## 3. Verify delivery

Run `kwatch lint --check` where PagerDuty credential checks are supported, or
use the diagnostics `/test-alert` endpoint for an end-to-end notification.
The [PagerDuty channel guide](/docs/channels/pagerduty) covers routing, retry,
fallback, and compact delivery options.

![Copy the PagerDuty integration key](/img/blog/kwatch-pagerduty/5.png)

You should now receive a PagerDuty incident when kwatch detects a configured
Kubernetes failure:

![PagerDuty incident from kwatch](/img/blog/kwatch-pagerduty/6.png)

For more destinations, browse the [complete provider reference](/docs/channels/providers).
