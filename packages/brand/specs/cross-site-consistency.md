# Cross-site consistency audit (web, docs, app)

Scope: `kwatch.dev/apps/web` (Astro), `apps/docs` (Docusaurus), `apps/app` (Vite/React), against `packages/brand/tokens.css`. Design only. Paths are under `/Users/macos/kwatch-dev/kwatch.dev/`.

## What already matches
All three import `packages/brand/tokens.css` (web via `layouts/Base.astro`, docs via `src/css/custom.css`, app via `src/styles.css`). Same families, pill-shaped buttons, hairline `--line` borders, light/dark from the system.

## Inconsistencies and fixes

| # | Area | Finding | Fix |
