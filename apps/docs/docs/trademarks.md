# ™️ Trademarks

Kwatch and the Kwatch logo are trademarks of the Kwatch project owner. The source
license does not grant permission to use those marks in a way that suggests an
unofficial build, fork, hosted service, or modified distribution is the official
Kwatch project.

You may refer to Kwatch factually when describing compatibility or integration.
For uses that could imply endorsement, sponsorship, or official distribution,
contact the project owner first.
