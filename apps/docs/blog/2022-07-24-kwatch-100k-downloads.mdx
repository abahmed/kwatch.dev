In July 2022, the [kwatch container package](https://github.com/abahmed/kwatch/pkgs/container/kwatch)
passed 100,000 pulls. This post records that historical milestone and thanks
the people who helped the project reach it.

<!--truncate-->

## Thank you to the community

Contributors improved alert destinations, documentation, and Kubernetes
monitoring while operators tried kwatch in their clusters and shared feedback.
See the [contributors list](https://github.com/abahmed/kwatch/graphs/contributors)
for the people behind those changes.

The project has evolved since 2022. The current kwatch turns Kubernetes
failures into incident alerts with a likely cause, supporting evidence, and a
next step. It runs in your own cluster and can send alerts to the tools your
team already uses.

## Try the current release

Use the [getting-started guide](/docs) for a quick tour, then install with the
[interactive manager](/docs/installation). Historical release notes in this
blog describe earlier versions and are not installation instructions for the
current release.

If you have an idea or find a problem, open an
