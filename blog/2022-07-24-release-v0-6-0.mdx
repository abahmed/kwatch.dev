<!--truncate-->

> This is a historical release note. For current installations and upgrades,
> use the [interactive `kwatch.sh` manager](/docs/kwatch-manager).

* Fix copy-paste mistake for reasons parsing by @simonfrey in #110

## ⬆️ How to Upgrade

For a current installation, run the manager again and choose **Upgrade**. It
handles release selection, readiness checks, and the Secret-backed configuration
for you.
